# Contributing

> **⚠️ Fork Notice**: This is a fork of the original Minha Receita project with adjustments for the new Brazilian Federal Revenue SERPRO+ infrastructure. See [FORK_CHANGES.md](FORK_CHANGES.md) for details.

## Original Project

For contributing to the upstream project, please visit the [original repository](https://codeberg.org/cuducos/minha-receita).

O guia de contribuição original é parte da [documentação](https://docs.minhareceita.org/contributing).

## Fork-Specific Contributions

If you want to contribute to this fork specifically (SERPRO+ infrastructure adaptations), please:

1. Check [FORK_CHANGES.md](FORK_CHANGES.md) for understanding the modifications
2. Test your changes with the new WebDAV infrastructure
3. Ensure compatibility with the original project's API and database schema
4. Update documentation if needed
